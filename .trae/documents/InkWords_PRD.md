# Message_Queue PRD

## 产品定位

`Message_Queue` 是一个面向学习和演示的简易消息队列项目，用于帮助理解 Broker、Exchange、Queue、Binding、消息持久化以及发布/订阅的基本工作流。

## 目标用户

- 想理解消息队列核心概念的学习者
- 想通过 C++ / protobuf / muduo 练习系统设计与工程结构的人

## 当前版本目标

- 保持核心消息队列实现逻辑可运行
- 让仓库结构更清晰、更适合阅读
- 降低首次进入仓库后的理解与构建成本

## 关键需求

- 提供清晰的源码、测试、数据、第三方依赖分层
- 提供统一的仓库级构建入口
- 保留学习性质的 playground 代码，但不干扰主链路
- 在 README 中说明依赖、构建、运行与限制

## 非目标

- 不将当前版本包装为生产级消息中间件
- 不在本轮重构中大规模改动核心业务实现
